# ThriveWeaver

A simple ThriveWeaver Engine for Distributed event driven architecture.

With ThriveWeaver, you get a lightweight tool that stays out of your way.

**What you get**

- A simple ThriveWeaver Engine for
- Distributed event driven architecture

## Key Features

- A simple ThriveWeaver Engine for
- Distributed event driven architecture

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/ThriveWeaver.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
